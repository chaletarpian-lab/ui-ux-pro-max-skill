# Base de contexte Arpian

Source de vérité partagée pour tous les agents travaillant sur les contenus
du Chalet Arpian (Valmorel). Toujours lire dans cet ordre :

1. `00-marque.md` — qui est Arpian, les lieux, l'audience, les interdits *(tous les agents)*
2. `01-voix-editoriale.md` — ton, structures, formules *(agents copy)*
3. `../design-system.md` + `02-production-slides.md` — visuel & pipeline *(agents prod/retouche)*
4. `03-assets.md` — inventaire photos, logo, slides, légendes validées *(tous)*
5. `ORCHESTRATION.md` — rôles, déroulé projet, modèle de brief *(chef d'orchestre)*

Règle d'or : cette base prime sur les souvenirs de conversation. Si un fait
manque, on demande au client — on n'invente pas.
